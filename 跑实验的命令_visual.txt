================================================================
对比实验：Qwen3-VL · VideoMME · 32 帧
模型：Qwen3-VL-8B-Instruct
================================================================
目的：对比"无压缩 baseline" vs "VidCom2 R=25% 压缩"在 VideoMME 上的逐题答题情况

运行前先激活环境：
  source /mnt/cpfs/gaoyizhuo-20260417/setup_env.sh

注意：8 卡全占，两条命令必须串行（跑完一个再起下一个）

================================================================
【1】Baseline（无压缩）· Max=64 · VideoMME
================================================================
setsid bash -c '
source /mnt/cpfs/gaoyizhuo-20260417/setup_env.sh
unset COMPRESSOR R_RATIO
accelerate launch --num_processes=8 \
  -m lmms_eval \
  --model qwen3_vl \
  --model_args pretrained=Qwen/Qwen3-VL-8B-Instruct,attn_implementation=flash_attention_2,max_num_frames=64 \
  --tasks videomme \
  --batch_size 1 \
  --log_samples \
  --log_samples_suffix baseline_32f_videomme \
  --output_path ./logs/
' > run_baseline_32f_videomme.log 2>&1 < /dev/null & disown

================================================================

【3a】小规模测试（--limit 64 + FILTER，验证白名单 dump 正确）
================================================================
# 必须满足的约束（见 DUMP_BUDGET.md）：
#   --batch_size 1        dump 代码取 chunk[0]，batch>1 会丢样本
#   COMPRESSOR=vidcom2    只有 vidcom2 的 forward 会写 budget.json
#
# 多进程（--num_processes=8）安全：每个进程独立 Python 解释器，
# 各自维护自己的 _current_video_id，互不干扰。和 baseline 实验一致用 8 卡。
#
# 环境变量：
#   COMPRESSOR=vidcom2               开启 VidCom2 压缩
#   R_RATIO=0.25                     基础保留比例 25%
#   DUMP_BUDGET=1                    开启 dump 模式（零开销保证：不设则完全不执行）
#   DUMP_BUDGET_DIR=./budget_data/   输出目录
#   DUMP_BUDGET_FILTER=./degraded_video_ids.txt
#                                    白名单，只处理这 139 个视频，其他样本跳过
#
# --limit 64：只跑前 64 道题验证白名单生效（8 卡每张 ≥8 道，避免 "no docs" 错误）
source /mnt/cpfs/gaoyizhuo-20260417/setup_env.sh
export COMPRESSOR=vidcom2 R_RATIO=0.25
export DUMP_BUDGET=1 DUMP_BUDGET_DIR=./budget_data_32f/
export DUMP_BUDGET_FILTER=./degraded_video_ids_32f.txt

accelerate launch --num_processes=8 -m lmms_eval \
  --model qwen3_vl \
  --model_args pretrained=Qwen/Qwen3-VL-8B-Instruct,attn_implementation=flash_attention_2,max_num_frames=32 \
  --tasks videomme \
  --batch_size 1 \
  --limit 64 \
  --log_samples \
  --log_samples_suffix dump_filter_test \
  --output_path ./logs/
